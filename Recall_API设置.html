🔌 AI 模型设置

配置大模型 API 后，AI 答疑、归因推荐等功能将由真实模型驱动。由于浏览器安全策略限制，前端不直接调用模型 API，需要通过本地 FastAPI 后端代理。

🚀 先启动后端服务（只需一次）：
1. 打开终端，进入 backend 目录
2. 安装依赖：pip install -r requirements.txt
3. 复制配置文件：cp .env.example .env，编辑填入 DEEPSEEK_API_KEY=sk-xxx
4. 启动：python main.py
5. 看到 Uvicorn running on http://0.0.0.0:8000 后再点「测试连接」
